# 위젯 표시와 클릭 동작 정의

## 공통 표시

- 숫자 요약은 아이콘, 사용자가 정한 이름, 값과 단위를 가진 카드로 표시한다. 최신값, 전체 장비 수, 계산 지표, 사용량·전력 합계·최대수요전력이 대상이다.
- 여러 측정값, 차트, 순위, 테이블, CCTV는 내용에 맞는 영역을 사용하되 제목, 색상, 여백, 상태 표시와 편집 동작을 통일한다.
- 데이터 없음은 0과 구분해 표시한다. 수집 지연과 일부 누락은 값과 함께 표시한다. 단위가 없으면 임의로 단위를 붙이지 않는다.
- 사용자가 선택한 색상, 디자인, 위젯 제목, 저장한 크기와 위치를 반영한다. 편집 모드의 카드 선택·이동은 상세 차트 열기와 구분한다.

## 현재 클릭 동작

트렌드 창의 기간과 집계 간격은 위젯마다 설정하며, 기존 위젯 기본값은 최근 3일·15분이다. 차트는 선 그래프로 표시하며 날짜와 단위, 시리즈를 구분한다. 데이터가 없으면 현재 창이 열리지 않는다. 아래의 개선 기준은 구현 요청이며 현재 동작을 의미하지 않는다.

| 위젯 | 현재 표시 | 현재 클릭 시 표시 |
| --- | --- | --- |
| 최신값 | 선택한 장비와 측정 항목의 최근값 카드 | 각 측정 항목의 설정된 기간 추이. 단위는 최대 두 종류 |
| 최신값 테이블 | 장비별 측정값과 선택한 열 | 최신값과 같은 원본 측정 추이. 표의 열 구성과 차트가 반드시 일치하지는 않음 |
| 장비 수 | 전체·모델별 수 | 클릭 차트 없음. 이력 데이터가 별도로 필요 |
| 추이 차트 | 설정된 기간·장비·측정 항목의 시계열 | 상세 차트에 설정한 기간과 간격으로 장비별 시리즈를 다시 조회 |
| 사용량·사용량 순위 | 누적 계량값의 기간 첫값과 마지막값의 차이 | 설정된 기간의 **누적 계량값** 추이. 기간별 사용량 추이가 아님 |
| 전력 합계·전력 순위 | 기간 마지막 전력과 장비별 순위 | 설정된 기간의 장비별 원본 전력 추이 |
| 최대수요전력 | 완전한 15분 평균 전력 합계 중 최댓값과 시각 | 설정된 기간의 장비별 원본 전력 추이. 15분 합계나 최대값 그래프가 아님 |
| 계산 지표 | 저장된 계산 결과 | 계산 결과의 설정된 기간과 간격에 따른 추이 |
| 공기선도 | 온도·습도 지점 | 온도 평균과 상대습도 평균의 시간별 추이 |
| 전력 분배 | 그룹별 최신 전력 비율 | 그룹별 전력 합의 시간별 추이 |
| CCTV | 영상과 카메라 선택 | 차트 없음. 영상 조작 |

실제 클릭 가능 여부는 최신 데이터 및 단위 조건에 따라 달라진다. 해당 코드는 `widget-dashboard.html`의 `trendAvailability`와 `openTrendModal`을 기준으로 한다. 계산 지표는 별도 계산 지표 API, 일반 추이는 `GET /api/manager/query/widget-trend`, 차트는 `GET /api/manager/query/chart`를 사용한다.

## 상세 차트 개선 기준

아래는 구현을 위한 제안이다. 데이터 의미가 달라지는 차트는 이름과 계산 기준을 확인해 API와 함께 구현한다.

| 위젯 | 클릭 후 기본 화면 | 필요한 정보 |
| --- | --- | --- |
| 최신값·테이블 | 선택한 장비와 항목의 시간별 선 그래프 | 항목·장비별 범례, 단위별 축, 수집 시각과 툴팁 |
| 장비 수 | 선택 대상의 장비 목록과 모델별 분포 | 현재 수와 필터. 과거 장비 수를 표시하려면 이력 수집 필요 |
| 추이 차트 | 저장한 기간·시리즈·차트 유형을 유지한 확대 차트 | 범례, 시간축, 단위별 Y축, 마우스 툴팁, 기간 변경 |
| 오늘·이번 달·지난달 사용량 | 선택 기간의 사용량 막대그래프 | 사용량 차분을 시간·일 단위로 합산. 누적 계량기 초기화와 수집 누락을 구분 |
| 사용량 순위 | 선택 기간의 장비별 사용량 막대그래프 | 동일 단위, 순위, 장비명과 사용량 |
| 전력 합계·전력 순위 | 합계와 장비별 전력 추이 | 순간 전력의 단위와 집계 간격, 장비별 범례 |
| 최대수요전력 | 15분 평균 전력 합계 선 또는 막대그래프 | 최대점과 시각, 15분 구간의 완전성. 개별 장비 값의 합계 기준 |
| 계산 지표 | 계산 결과의 시간별 추이 | 지표 이름, 단위, 조회 기간, 결측·계산 실패 표시 |
| 공기선도 | 온도·습도 시간 추이와 공기선도 | 선택한 센서, 온도·습도 각 축과 단위 |
| 전력 분배 | 그룹별 전력 추이 | W/kW, 그룹별 범례, 합계 계산 기준 |
| CCTV | 카메라 영상 확대 및 전환 | 선택 카메라와 재생 상태 |

- 데이터 없음, 로딩, API 오류를 창에 표시한다. 차트에 값이 없을 때 클릭해도 반응이 없는 상태를 피한다.
- 툴팁은 시각, 시리즈 이름, 값과 단위를 표시한다. 숫자 0을 누락으로 처리하지 않는다.
- 저장된 기간과 화면의 기간이 다르면 실제 조회 기간을 명확히 표시한다. 현재 일반 사용량 집계의 날짜 경계는 UTC이며, 한국 시간 기준 표시가 필요한 경우 서버 집계 기준 변경이 필요하다.
- 테이블과 순위 등 인터랙션이 있는 위젯은 버튼·정렬·스크롤 조작이 차트 열기를 방해하지 않게 한다.
- 장비별 값과 총합이 다른 의미일 때 차트 제목에 이를 명시한다. 누적 전력량, 기간 사용량, 순간 전력, 최대수요전력은 각각 단위와 계산이 다르다.

## 확인 항목

- 같은 크기의 단일 숫자 카드에서 제목, 숫자, 단위, 아이콘과 상태가 겹치지 않는다.
- 카드 디자인과 색상을 바꾸고 저장한 뒤 다시 열어도 적용된다.
- 모든 유형의 클릭 동작을 데이터 있음·없음·조회 실패·편집 모드에서 확인한다.
- 사용량·최대수요 상세 차트는 실제 계산 결과와 시간대가 맞는지 API 결과와 대조한다.
