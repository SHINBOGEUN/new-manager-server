선택 자산

왼쪽에서 자산을 선택하세요.

자산 운영 상태

운영중 → 점검 중/장애/미사용 → 폐기 흐름으로 관리합니다. 미사용·폐기는 수집과 장비 기반 위젯 대상에서 자동 제외됩니다.

자산을 선택하면 운영 상태를 전환할 수 있습니다.

자산 변경 이력

자산을 선택하면 자산번호·시리얼·상태 변경 이력이 표시됩니다.

Rack 배치

자산을 선택하면 Rack 위치와 U 배치를 등록할 수 있습니다.

Rack 변경 이력

자산을 선택하면 배치 변경 이력이 표시됩니다.

장비 이미지

자산을 선택한 뒤 JPG, PNG, WEBP 이미지(최대 10MB)를 등록하세요.

관련 문서

자산을 선택한 뒤 문서 파일을 등록하세요. 파일 형식 제한 없이 최대 20MB까지 가능합니다.

2D 도면 · 3D 모델 파일

현재 선택한 장비 자산에 파일을 저장합니다. 2D는 SVG/PNG/JPG/WEBP, 3D는 OBJ/GLB를 지원합니다. 각 파일은 20MB 이하입니다.

자산을 선택하면 이 자산의 도면과 모델 파일을 등록·미리보기할 수 있습니다.

Rack 보기

Rack을 선택하세요.

3D 자산 관리

도면에 배치할 모델을 등록하고 카테고리, 이름, 기본 크기, 파일을 관리합니다. 카테고리는 도면의 3D 모델 선택 창에도 적용됩니다.

새 모델 등록

새 모델은 20MB 이하 GLB 파일이 필요합니다. 기존 모델은 파일을 선택하지 않으면 현재 파일을 유지합니다. 크기 변경은 기존 도면에도 반영됩니다.

등록된 3D 모델

건축·공간 / 공장 설비

기본 자산은 형태를 바꾸려면 화면 코드 수정이 필요합니다. 여기서는 이름과 선택 목록 표시 여부를 관리합니다. 새 형태는 위에서 GLB 모델로 등록할 수 있습니다.

사용 가이드

      
장비 등록부터 공간 구성과 모니터링까지 필요한 순서대로 시작하세요.

      

        
1. 장비 등록
장비 관리에서 장비를 등록하고 위치와 통신 방식을 선택합니다. 같은 종류의 장비는 장비 모델에 측정 항목을 한 번 설정해 함께 사용할 수 있습니다.

        
2. 데이터 수집 확인
데이터 수집에서 최신 저장 시각과 지연 여부를 확인합니다. SNMP·Modbus는 수집 작업을 설정하고, MQTT는 연결과 장비 식별자를 설정합니다.

        
3. 공간과 랙 구성
자산 · 랙에서 장비 자산과 랙 용량, 장착 위치를 관리합니다. 공간 · 환경의 연필 버튼을 눌러 도면에 설비와 위젯을 배치하고 저장하세요.

        
4. 화면 구성
설정의 화면 구성에서 페이지에 표시할 장비와 2D·3D 보기 방식을 선택합니다. 각 모니터링 화면에서 연필 버튼으로 위젯을 추가하고 크기를 조절할 수 있습니다.

        
5. 경보와 이력 확인
알람에서 장비별 주의·위험 기준을 설정합니다. 이상이 발생하면 진행 상태와 복구 이력을 확인하고, 데이터 분석에서 같은 시간대의 측정값을 비교하세요.

        
도면 편집의 기본
편집 → 바닥 설치 → 설비 배치 → 저장 순서로 작업합니다. 랙을 더블클릭하면 장비 장착과 위젯을 설정할 수 있습니다. 편집 중 취소·되돌리기와 잠금으로 배치를 관리하세요.
