주소는 문서 번호가 아닌 실제 요청 주소(0 기반)입니다. 예: 문서 11267 → 요청 11265. 미등록 대상 장비는 먼저 장비 목록에서 생성하세요. 테스트 값은 배율 적용 후 원값이며, 기존 스크립트의 소수 둘째 자리 버림은 적용하지 않습니다.

비트 분리 설정

            
원본값은 그대로 저장합니다. 최하위 비트가 0번이며, 원하는 길이만큼 추출해 별도 항목으로 저장합니다. 추출값을 다른 값으로 저장하려면 아래에서 변환 규칙을 추가하세요. 규칙이 없으면 추출값 그대로 저장됩니다.
